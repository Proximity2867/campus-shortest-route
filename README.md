# Campus Shortest Route Finder

A simple C program that finds the shortest route between locations on a college campus using Dijkstra's Algorithm.

## Features

- Uses an adjacency matrix to represent the graph
- Finds shortest distances from a selected location
- Displays the shortest path
- Uses Dijkstra's Algorithm
- Menu-driven program

## How to Run

Compile the program:

```bash
gcc main.c -o campus-route
```

Run it:

```bash
./campus-route
```

## Example Locations

- Main Gate
- Library
- Computer Department
- Laboratory
- Auditorium

## Algorithm

Dijkstra's Algorithm is used to find the shortest distance from the selected source location to all other locations.

Time complexity: `O(V²)`
